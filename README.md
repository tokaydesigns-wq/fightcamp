# FightCamp

A free phone app for martial artists (boxing, Muay Thai, BJJ, wrestling, MMA).

- **Train**: log sessions and see your weekly minutes, streak and an 8-week chart.
- **Food**: log meals (calories and protein) and your weight against daily targets.
- **Camp**: set a fight date for a countdown and tips for each stage of camp.
- **Learn**: type something like "Lomachenko footwork" to get the fighter's Wikipedia profile
  and a 4-week drill program for that technique, with a checklist.

Everything is saved on your device. No account, no ads, no API keys.

To try it on this computer, double-click `Start FightCamp.bat`.
